# Demonstration release

Backend release `v0.1.0` accompanies Flutter `0.1.0+1`. Annotated tags identify immutable release snapshots in each repository. Use semantic major.minor.patch versioning; increment patch for fixes and minor for new demonstration features until the production 1.0 release.

This release does not change the API or schema. Existing hosted data and configuration remain in place. The web frontend is deployed in `app/`; the root redirect already points there. The local PHP project and database are retained.
